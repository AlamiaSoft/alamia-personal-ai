# AgentHost Terminology Glossary

## Canonical Terms

### AgentHost
The local-first daemon, platform, and CLI tool that discovers host resources, manages runtime lifecycles, resolves execution profiles, and enforces security boundaries.

### Candidate Runtime
An external agent framework or execution engine (e.g., Agent Zero, OpenJarvis) wrapped by an AgentHost `RuntimeAdapter`.

### RuntimeAdapter
The standardized contract interface defining how AgentHost controls and communicates with an agent runtime (`start`, `stop`, `health`, `execute`, `stream`, `logs`, etc.).

### Execution Profile
The composite unit representing a complete agent runtime configuration:
$$\text{Execution Profile} = (\text{Runtime}, \text{Model}, \text{Hardware}, \text{Tools}, \text{Mode})$$

### ModelProfile
Machine-readable profile defining a model's capabilities, context window, hardware requirements (VRAM/RAM), pricing economics, limits, and empirical test evidence/confidence.

### TaskRequirements
A structured classification generated by the Task Analyzer defining required capabilities (`browser`, `filesystem`, `code_execution`, `vision`, `cloud_allowed`, etc.) for a specific request.

### Capability-Driven Tool Injection
The technique of injecting only the tool subset necessary for a task's requirements into the runtime prompt, minimizing token overhead and latency.

### Profile Preflight
A comprehensive validation check performed when selecting or modifying an execution profile, verifying container availability, model weights, and hardware limits.

### Task Preflight
A lightweight check performed prior to request execution to confirm capability alignment, token budgets, and quota state.

### Evidence Confidence Score
A multiplier ($0.0 - 1.0$) based on the origin of model capability data (vendor metadata vs. empirical local machine benchmark).
